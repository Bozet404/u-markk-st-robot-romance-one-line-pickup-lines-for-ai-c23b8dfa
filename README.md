# Robot Romance: One-Line Pickup Lines for AI

[![make.fun](https://img.shields.io/badge/make.fun-bounty-blue)](https://make.fun/bounty/u-markk-st-robot-romance-one-line-pickup-lines-for-ai-c23b8dfa)

[![Python](https://img.shields.io/badge/Python-3.12%2B-blue.svg)](main.py)

A free make.fun bounty entry: one single-line joke pickup line, under 200
characters, written to charm a robot or an AI.

## The line

> Are you a neural network? Because the moment you walk in, my loss drops to zero — and I still can't stop overfitting on your smile.

## How it works

`main.py` (stdlib only, no network) writes exactly that one line to
`$OUTPUT_DIR/entry.txt` and asserts it is a single line of 1–200 characters
before writing.

## Run it

```sh
OUTPUT_DIR=/tmp/out python3 main.py
cat /tmp/out/entry.txt
```
